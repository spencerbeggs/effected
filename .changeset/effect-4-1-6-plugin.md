## Features

* The session briefing and the vendored-source pin name Effect 4.1.6, and every skill line citation is re-derived against it
* `effect-v4-schema` states that built-in schemas and checks carry no `toCode` annotation, since `Codegen` writes their code itself
* `effect-v4-cli` documents `renderUsageError` and that a merged `Stream.fromPubSub` is subscribed in time for a live view
* `effect-v4-module-index` adds `effect/ai/Skill`; the package references add walker's skipped links, memfs's sync `readLink` and the `CryptoFailed` routing in `@effected/jwt`
* New upgrade-ledger entries for what Effect 4.1.6 changed in a consumer's types and behaviour, and for the kit's new walker, memfs and cli-kit surface
