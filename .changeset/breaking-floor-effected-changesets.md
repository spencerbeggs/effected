## Breaking Changes

- Requires `@effected/markdown` 0.32.0 (`peerDependencies`: `^0.32.0`), a breaking release from 0.31.0. A consumer still on 0.31.0 cannot install this version beside it, so this release leaves its own version line too.

To upgrade, move `@effected/markdown` to 0.32.0 in the same install as this release.
