features:
  - title: Designed v4-first
    details: Not a v3 codebase lifted forward. Every package was designed against Effect v4's consolidated core, so there are no compatibility shims and no leftover shapes that only made sense in v3.
    icon: 🧬
  - title: Parsers are schemas
    details: JSONC, YAML, TOML, Markdown, SemVer, SPDX and globs all parse through Schema classes with a FromString codec. A version or a license expression embeds directly in your domain schema instead of being validated on the side.
    icon: 🧩
  - title: Nothing throws
    details: Every failure a caller could reasonably handle is a tagged error on the typed E channel, carrying the offending input. Malformed data fails as a value, never as an unhandled exception.
    icon: 🛡️
  - title: A tier per package
    details: Pure, boundary or integrated — a published statement of what depending on a package costs your install. Boundary packages require FileSystem and Path in R and never provide a backend, so the edge of your program decides.
    icon: 📐
  - title: Testable by construction
    details: Because IO goes through core's service contracts, swapping a real disk for the in-memory volume in @effected/memfs is a layer change. Misbehaviour is injected as a fault handler rather than faked with a stub.
    icon: 🧪
  - title: Built for real tools
    details: Monorepo graphs, pnpm catalogs and lockfiles, git introspection, the GitHub API, the Actions runtime, SBOMs and attestation, SQLite-backed state — the machinery CLIs and CI actually run on.
    icon: 🛠️
