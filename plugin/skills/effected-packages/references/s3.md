# @effected/s3

A minimal client for one bucket of an S3-compatible object store (AWS S3, Cloudflare R2, MinIO, DigitalOcean Spaces): conditional `put`, `get`, `head`, `delete`, and a strict ListObjectsV2 (`list`, and `listAll` as a `Stream`), signed with `@effected/crypto`'s `SigV4`. Boundary tier: `effect` is the only peer, `@effected/crypto` the only dependency, and no `node:` import anywhere, so the same code runs on Node and Cloudflare Workers.

Reach for it when a service stores raw objects, instead of the AWS SDK or a hand-rolled client over `SigV4`. A GitHub Action that wants framed blobs on S3 reaches for `BlobStore.layerS3` in `@effected/github-actions` instead; that one wraps every object in its own envelope and has no listing.

## Import

```ts
import { S3Client, S3InvalidRequest, S3ListPage, S3MalformedResponse, S3NotFound, S3NotModified, S3Object, S3ObjectHead, S3ObjectSummary, S3PreconditionFailed, S3PutResult, S3RequestFailed, S3TransportError } from "@effected/s3";
import type { S3ClientOptions, S3ClientShape, S3Credentials, S3DeleteError, S3Error, S3GetError, S3GetOptions, S3HeadError, S3ListAllOptions, S3ListError, S3ListOptions, S3PutError, S3PutOptions } from "@effected/s3";
```

**Platform**: three core services are required when the client is made and resolved once there, so every method's `R` is `never`.

| Service | Any WebCrypto runtime (Workers included) | Node |
| --- | --- | --- |
| `HttpClient.HttpClient` | `FetchHttpClient.layer` from `effect/http` | the same, or `NodeHttpClient.layerUndici` from `@effect/platform-node` |
| `Digest.Digest` | `Digest.layerWebCrypto` from `effect/crypto` | `NodeCrypto.layerDigest` |
| `Mac.Mac` | `Mac.layerWebCrypto.pipe(Layer.provide(SecureRandom.layerWebCrypto))` | `NodeCrypto.layerMac` |

## Core API

- **`S3Client.layer(options)`** → `Layer<S3Client, never, HttpClient | Digest | Mac>`, the service for one bucket. Bind it to a `const`: a parameterized factory mints a fresh layer per call. **`S3Client.make(options)`** → `Effect<S3ClientShape, never, HttpClient | Digest | Mac>` is the same client as a value, for a program that talks to two buckets.
- **`S3ClientOptions`** — `bucket`, `region` (`auto` for R2), optional `endpoint` (AWS's regional endpoint when omitted), `credentials: S3Credentials` (`accessKeyId`, `secretAccessKey`, optional `sessionToken`, all `Redacted<string>`), and `forcePathStyle`, which defaults to `true` with an endpoint and `false` for AWS, except that a bucket name holding a dot is addressed path style over `https`, because as a host label it would not match the wildcard certificate.
- **`put(key, body: Uint8Array | string, options?)`** → `Effect<S3PutResult, S3PutError>`. `S3PutOptions`: `ifNoneMatch` (`"*"` or an ETag), `ifMatch`, `contentType`, `metadata`. `S3PutResult`: `etag`, optional `versionId`.
- **`get(key, options?)`** → `Effect<S3Object, S3GetError>`. `S3GetOptions`: `ifNoneMatch`, `range` (a raw `Range` value such as `bytes=0-9`). `S3Object` is the head's fields plus `body: Uint8Array`, optional `contentRange` and a `text` getter (UTF-8).
- **`head(key)`** → `Effect<S3ObjectHead, S3HeadError>`. `S3ObjectHead`: `key`, `etag`, `contentLength`, `metadata` (the `x-amz-meta-*` headers, names lower-cased, prefix removed), optional `contentType`, `lastModified`, `versionId`.
- **`delete(key)`** → `Effect<void, S3DeleteError>`. Deleting a missing object succeeds, as on S3.
- **`list(options?)`** → `Effect<S3ListPage, S3ListError>`, one page. `S3ListOptions`: `prefix`, `delimiter`, `startAfter`, `continuationToken`, `maxKeys`. `S3ListPage`: `keys`, `commonPrefixes`, `isTruncated`, `nextContinuationToken: Option<string>`.
- **`listAll(options?)`** → `Stream<S3ObjectSummary, S3ListError>`, following continuation tokens. `S3ListAllOptions`: `prefix`, `startAfter`, `maxKeys` (the page size). `S3ObjectSummary`: `key`, `size`, `lastModified`, optional `etag`, `storageClass`.

## Errors

Seven tagged errors, each with `operation` (`S3Operation`), `bucket` and `key` (the prefix, for a listing). `S3PutError`, `S3GetError`, `S3HeadError`, `S3DeleteError` and `S3ListError` name exactly what each operation can raise; `S3Error` is all seven.

| Error | When |
| --- | --- |
| `S3NotFound` | `404` to a `head`, or a `404` to a `get` whose `<Error>` document's `Code` is `NoSuchKey` |
| `S3NotModified` | `304` to a `get` with `ifNoneMatch`; carries the `etag` |
| `S3PreconditionFailed` | `412` to a conditional `put` |
| `S3RequestFailed` | any other refusal; `status`, and `code`, `s3Message`, `requestId` when the body was an `<Error>` document, a `200` `<Error>` listing included |
| `S3MalformedResponse` | an answer the client cannot read: a listing whose root is not `ListBucketResult`, a page missing an element it depends on, a success without an ETag; `status`, `expected`, `received` |
| `S3TransportError` | the request did not complete; `cause` is the redacted client error |
| `S3InvalidRequest` | the input cannot be sent; `reason` (`S3InvalidRequestReason`: `empty-key`, `key-too-long`, `dot-segment`, `metadata-name`, `metadata-duplicate`, `header-value`, `max-keys`) and `field`; nothing was signed or sent |

## Usage

```ts
import { S3Client } from "@effected/s3";
import { Effect, Layer, Redacted } from "effect";
import { Digest, Mac, SecureRandom } from "effect/crypto";
import { FetchHttpClient } from "effect/http";

const Archive = S3Client.layer({
  bucket: "build-webhooks",
  region: "auto", // R2
  endpoint: "https://<account>.r2.cloudflarestorage.com",
  credentials: {
    accessKeyId: Redacted.make("<access key id>"),
    secretAccessKey: Redacted.make("<secret access key>"),
  },
});

const AppLayer = Archive.pipe(
  Layer.provide(FetchHttpClient.layer),
  Layer.provide(Digest.layerWebCrypto),
  Layer.provide(Mac.layerWebCrypto.pipe(Layer.provide(SecureRandom.layerWebCrypto))),
);

// First write wins: a redelivered key is an answer, not a failure.
const archive = (key: string, json: string) =>
  Effect.gen(function* () {
    const s3 = yield* S3Client;
    return yield* s3.put(key, json, { ifNoneMatch: "*", contentType: "application/json" }).pipe(
      Effect.as("created" as const),
      Effect.catchTag("S3PreconditionFailed", () => Effect.succeed("exists" as const)),
    );
  });
```

## Traps

- **A `404` is not always a missing object.** On a `get` or `delete` only the `NoSuchKey` code counts: a `NoSuchBucket`, an HTML page from a proxy or an empty body is `S3RequestFailed`, so a misrouted endpoint never reads as "no such object". A `head` answer has no body to tell them apart, so every `404` to a `head`, a missing bucket included, is `S3NotFound`.
- **A listing never reads as empty by accident.** A `200` `<Error>` is `S3RequestFailed`, and any other root is `S3MalformedResponse`; so is a truncated page with no token, an entry with no `Key`, or a `KeyCount` that disagrees with what was read. `listAll` also fails on a repeated continuation token rather than looping.
- **`listAll` takes no `delimiter`,** because a stream of objects would drop the common prefixes. Page through `list` to read them.
- **ETags keep their quotes,** so `ifMatch: head.etag` round-trips. Never strip them.
- **Bad options die at construction,** when the layer is built or `make` runs: an empty bucket, a bucket with `/`, an endpoint that is not an `http:` or `https:` URL. They are a wiring mistake, not a typed error. Bad per-call input (a key, metadata, `maxKeys`) is `S3InvalidRequest`.
- **No timeout and no retry inside the client.** Bound an operation with `Effect.timeout` and retry with `Effect.retry` at the call site; a timed-out request is interrupted and its connection released.
- **Signing time is `DateTime.now`,** so `TestClock` drives it. A broken `Mac` layer dies rather than surfacing a typed `CryptoError`.
- **Keys holding a control character** make the listing that contains them fail with `S3MalformedResponse`: XML 1.0 cannot carry the character, and the client does not ask for URL-encoded keys.

## Not included

Multipart upload, copy, bucket operations, presigned URLs, the version-1 listing, and streaming bodies: `put` takes the whole body and `get` returns it whole.
