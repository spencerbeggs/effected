# Limitation

* [@effected/cli is not a CLI framework](cli-is-not-a-framework.md) - The package deliberately carries no argument parsing, no platform package, and no interactive terminal UI.
* [@effected/commands does not supervise or archive processes](commands-no-process-supervision.md) - Reap-after-detach, readiness polling, and archive helpers are deliberately absent, and stay a level up.
* [@effected/github does not own every GraphQL document](github-graphql-schema-not-owned.md) - A document over a consumer-specific domain (project boards, etc.) is deliberately not modelled in the kit.
* [A block-mapping key longer than 1024 rendered characters spills to explicit-key form](yaml-explicit-key-spill.md) - YAML 1.2's implicit-key length cap forces the stringifier to switch a long key from block-implicit to explicit-key form, changing the emitted shape.
* [A cursor-less jsonl query reads the whole file into memory](jsonl-query-not-window-bounded.md) - Unlike latest and last-valid-line reads, query and the replay half of a resumed subscription are not window-bounded; a cursor-less query over a large journal pays for the whole file.
* [A package manifest cannot say who supplied it, who assembled the BOM, or when](what-a-manifest-cannot-say.md) - SbomMetadataSource refuses to fabricate supplier, BOM-author and timestamp fields a package.json cannot honestly answer.
* [Bun's package-tuple integrity position is assumed, not documented](lockfiles-bun-tuple-shape-under-documented.md) - Integrity data is read from an inferred index in bun's package tuple because bun does not document the tuple's shape.
* [Decoding a JsonLdDocument silently drops the additional catch-all](schema-org-decode-direction-unimplemented.md) - JsonLdDocument only implements the encode direction; a Schema decode of the wire form succeeds but does not reconstruct which fields were originally flattened from a node's catch-all.
* [Git error classification uses unanchored substring matching on stderr](git-stderr-classification-unanchored.md) - A path or ref name that literally contains one of the classification phrases could theoretically misclassify; anchoring is deferred until a real collision is observed.
* [MarkdownFormat.modify refuses frontmatter, list items, table rows and the root](markdown-modify-refuses-frontmatter.md) - The node-replacement edit API fails typed rather than replacing a frontmatter node, a list item, a table row, or the document root.
* [NpmRegistry does not cache repeated packument reads](npm-no-packument-caching.md) - Several NpmRegistry read paths fetch the same registry document more than once in a single program — most visibly the per-version read's 405 packument fallback — and nothing caches it; the fix is deferred until a consumer's call pattern demonstrates the cost rather than the redundancy alone.
* [PeerCheck cannot answer yarn](workspaces-peer-check-yarn-and-suppression-axes.md) - PeerCheck reports supported false for yarn's virtual-locator peers, because the yarn lockfile records no join between a peer declaration and the instance that satisfied it.
* [The importer-name map carries names only](lockfiles-importer-name-map-carries-names-only.md) - withImporterNames rewrites pnpm workspace package names but leaves their placeholder version untouched.
* [The pnpm root importer is not represented as a package row](lockfiles-pnpm-root-importer-not-a-package-row.md) - Only non-root pnpm importers become workspace rows in the resolved packages array, so the root importer's own resolution is unrepresented.
* [There is no cross-run artifact lookup](actions-storage-no-cross-run-artifact-lookup.md) - The artifact module cannot fetch an artifact produced by a different workflow run; the API exists on GitHub's side but has no call site shaping it here yet.
* [Under the no-op hooks layer, a hook-injected catalog's range bump between two refs is invisible to a snapshot diff](workspaces-snapshot-hook-catalog-bump-between-refs.md) - Under ConfigDependencyHooks.layerNoop (the default composites), WorkspaceStateSnapshot.crossSeed cannot surface a range change made purely by bumping a config dependency between two refs, because neither ref's committed sources declare the catalog; a replaying layer detects it.
* [Yarn carries no resolved peer edges](lockfiles-yarn-carries-no-peer-edges.md) - The yarn Berry parser records dependency edges only; peer-dependency resolution is never populated because yarn resolves peers virtually.
* [config-file has no file-watching capability](config-file-no-watching.md) - The package offers no way to be notified when a loaded config file changes on disk.
* [jsonl terminal and quiescent semantics are journal-wide, not per-scope](jsonl-terminal-semantics-journal-wide.md) - A journal partitioned by scope cannot collapse independent per-scope loops into one file today, because terminal/quiescent state and current-state reads are both journal-wide, not sliced.
* [memfs's volume is invisible to anything that does not ask for the FileSystem service](memfs-what-the-volume-does-not-see.md) - memfs installs no hooks and patches no module registry, so direct node:fs calls, spawned processes, native-binding IO, and process.cwd() all silently bypass the volume.
