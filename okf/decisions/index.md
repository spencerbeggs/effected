# Decision

* [@effect/platform-node is a required peer in exactly one package](platform-node-peer-in-one-package.md) - github-actions is the only kit package with a required @effect/platform-node peer, because a GitHub Action always compiles into one Node process on a GitHub-provided runner; the licence is scoped to that overlay and does not generalize to any other package.
* [@effected/github owns the octokit runtime](github-owns-octokit-runtime.md) - Why the octokit client and the sealed-box crypto pair live in @effected/github rather than being pushed to consumers.
* [@effected/schema-org declines both available @effected edges](schema-org-declines-kit-edges.md) - license and version are typed to the vocabulary's own wide ranges rather than to @effected/spdx or @effected/semver, because a vocabulary's declared range is the contract.
* [@effected/vfs is deferred until a second consumer materializes](vfs-deferred-until-second-consumer.md) - A generic node_modules/-prefixed virtual filesystem with merge/prefix helpers and an environment seam is decided-but-unbuilt; it ships only when a second VFS consumer appears beyond the TypeScript-tooling one that motivated its shape, never speculatively.
* [A lockfile is a YAML stream, not always one document](lockfile-is-a-yaml-stream.md) - pnpm lockfiles using config dependencies are two YAML documents in one file, and lockfiles is parsed against that fact by position rather than by content heuristic.
* [A schema.org property gets one fixed arity, chosen toward many when uncertain](schema-org-property-arity-declines-collapse.md) - Every modeled property is either always a scalar or always an array, never a union of the two, and an uncertain case is modeled as an array because the two error costs are asymmetric.
* [A second published entrypoint is a measured cost, not a convenience](second-published-entrypoint.md) - A package adds a subpath export only when a structural test proves an unbundled consumer would otherwise pay to load a part of the graph it never touches.
* [A test needing FileSystem uses memfs, never a hand-rolled layerNoop stub](memfs-over-layernoop.md) - Migrate every test's filesystem double from FileSystem.layerNoop to @effected/memfs, because a hand-rolled stub only encodes the semantics its author remembered.
* [Azure is confined to three modules, not two](azure-blob-confined-to-three-modules.md) - The Azure blob client may only be imported by ActionCache, Artifact and BlobStore.githubCache — not by any shared internal helper.
* [CliLogger honours LogToStderr only as a force-all override](cli-logger-force-all-stderr-only.md) - Why the public LogToStderr reference can only push every level to stderr, never move one level back to stdout.
* [ConfigCodec is exempt from the sync primitive policy](codecs-exempt-from-sync-primitive-policy.md) - A ConfigCodec's Effect-returning members are not required to carry a synchronous Result twin, because their Effect return type expresses interface polymorphism, not a wrapped span.
* [Contract inversion is the default answer to a tier-dragging edge](contract-inversion-default.md) - When package A needs behaviour only package B can implement, A declares the narrow contract and B ships the layer implementing it, rather than A taking a direct dependency edge on B — the pattern now runs three times across the kit.
* [Decided against: a shared @effected/errors package](no-shared-errors-package.md) - A cross-package errors package was rejected for four reasons — the kit already has a shared error vocabulary in effect core, a central errors package inverts ownership and couples every error change to a cross-package release, Effect's error channel already composes unions structurally, and the genuine cross-boundary case already has a house pattern.
* [Each format package keeps its own options type](format-options-type.md) - No shared kit-wide formatter options shape; each package's options stay irreducibly format-specific.
* [Each plugin versions via its own private tracking package](plugins-version-via-private-tracking-packages.md) - Both plugins version and release independently of the kit's library waves, each through a private, never-published workspace package that exists only to give changesets something to version.
* [Each runtimes resolver exposes three lazy layer constants, not one configurable layer](cache-strategy-as-layer.md) - layer/layerFresh/layerOffline are memoized layer constants over a run-once population gate, never Effect.cached and never a fetch inside Layer.effect.
* [Every default reference time comes from Clock, never new Date()](runtimes-wall-clock-via-clock.md) - Phase logic reads DateTime.now so TestClock can drive it deterministically; no member reaches for the ambient wall clock directly.
* [Format entry points never return Effect](format-return-type.md) - A three-way return-type rule keyed on whether failure is possible; a tolerant formatter entry point never returns Effect.
* [Format-package naming is `*Format`, not `*Unvalidated`](format-naming.md) - The `*Format` concept class with total statics is the kit's naming convention; `*Unvalidated` is rejected.
* [Git failure classification happens once, in one private function](git-classification-happens-once.md) - No consumer of @effected/git ever string-matches stderr; a single private classify step in Git.ts is the only place that inspects stderr, stdout or exitCode.
* [GitHubClient keeps only the authenticated REST reads Bun and Deno need](runtimes-githubclient-honestly-scoped.md) - Shared JSON-over-HTTP machinery lives in internal/http.ts, used unauthenticated by the Node fetchers and authenticated by GitHubClient, over one shared HTTP error family.
* [Markdown dialects are a closed set with no public extension API](markdown-dialects-closed-set.md) - @effected/markdown exposes a dialect option (CommonMark or GFM) with no plugin mechanism, matching the yaml and toml packages' zero-plugin posture.
* [Markdown editing is offset-splice, not a lossless CST](markdown-editing-is-offset-splice.md) - @effected/markdown edits source via offset/length/content splices over the original text, matching the jsonc/yaml/toml edit vocabulary, rather than a lossless concrete syntax tree.
* [No SchemaVersioning.plan surface](schemastore-no-versioning-plan-surface.md) - SchemaVersioning ships no separate planning function, because catalogUrls already sorts and dedupes the version set a plan would compute.
* [No bin on the library — the CLI is a fixed-version companion package](schemastore-no-bin.md) - @effected/schemastore ships no bin entry; the schemastore executable lives in @effected/schemastore-cli, a bin-only companion released in a fixed group with the library.
* [No layerDefault on SchemaValidator or SchemaFile](schemastore-no-layer-default.md) - Every service-shaped module ships a real layer and a test layer; a third layerDefault would only be a name for one of the two that already exist.
* [No shipped templates/ directory](schemastore-no-shipped-templates-directory.md) - The bundler publishes only emitted src, LICENSE and README; the canonical schema-generator script a consumer copies lives outside the package.
* [Only package-json needs a tolerant formatting seam](format-tolerant-seam.md) - package-json is the one format package that adds a tolerant entry point; the other four and config-file add no new surface.
* [Provenance lives in the engine state, and is never hardcoded](runtimes-provenance-in-engine-state.md) - The release index carries a live/cache source marker set by whichever strategy actually populated it, so a stale snapshot is never reported as fresh.
* [Releases are changeset-driven and scope-agnostic](release-model.md) - CI builds the changesets present on a branch and releases exactly the packages they name — a whole-kit wave and a single-package patch are the same mechanism, every package stays 0.x and unstable until Effect v4 reaches GA, and breaking changes ride minors under exact-pin discipline.
* [SchemaFile's write-if-changed compares parsed content, not bytes](schemastore-write-if-changed-compares-content.md) - Content comparison is the default for write-if-changed, with byte-exact comparison an opt-out, because a repo that formats its JSON makes byte comparison never converge.
* [SchemaStore's own coverage tool is not reimplemented](schemastore-coverage-tool-not-reimplemented.md) - The package treats SchemaStore's own coverage checks as candidate inspiration only, rather than reimplementing them as a shipped feature.
* [Schemastore retiers from boundary to integrated for a direct ajv dependency](schemastore-retier-to-integrated.md) - The one package in the kit retiered after publishing, from boundary to integrated, to take ajv as a real validation engine rather than a contract-only seam.
* [Store is built on effect's own SQL core and @effect/sql-sqlite-node](store-v4-sqlite.md) - Store uses the SqlClient abstraction shipped inside effect core plus the Node sqlite driver, and hand-rolls its own reversible migration ledger rather than core's forward-only Migrator.
* [Store is named for its primitive, not its backend](store-named-for-primitive.md) - The package name and public surface describe a schema-versioned migrated SqlClient and a TTL cache — nouns any SQL driver could satisfy — never the specific SQLite implementation behind them today.
* [Generated objects are closed by default, departing from core's open default](schemastore-closed-objects-by-default.md) - StoreDocument.fromSchema generates with onExcessProperty: error so every object is emitted with additionalProperties false, because a published document is a contract; core's own default flipped open at rc.113 and the package no longer follows it.
* [The Draft-07 meta-schema constant keeps its trailing hash](schemastore-meta-schema-keeps-trailing-hash.md) - DRAFT_07_META_SCHEMA carries a trailing hash, matching the SchemaStore corpus convention and deliberately diverging from core's equivalent constant.
* [The MDX brace escape is presence-keyed, never a stringify option](markdown-mdx-escape-presence-keyed.md) - A tree carrying any MDX node additionally escapes { in text; the escape is triggered by a pre-scan of the tree, never by a caller-set option.
* [The NTIA minimum-elements report is a report, not a gate](ntia-report-not-a-gate.md) - NtiaReport is a pure function returning a compliance report; the caller decides whether non-compliance fails a run.
* [The Node schedule is keyed by release line, not by major](runtimes-node-schedule-by-release-line.md) - NodeScheduleEntry carries a line string ("20", "0.10") rather than a numeric major, because early Node majors collapse under Number.parseInt.
* [The ascend ceiling compares resolved paths and rejects a relative stopAt as a defect](ascend-ceiling-fails-closed.md) - Walker's ascend ceiling normalizes both sides before comparing and dies on a relative stopAt, closing a fail-open bug where an unnormalized ceiling silently let the scan reach the filesystem root.
* [The assembly module is named StoreDocument, not SchemaDocument](schemastore-module-naming-storedocument.md) - Naming the assembly module StoreDocument rather than SchemaDocument, to avoid a name that reads like the banned general-JSON-Schema scope.
* [The config companion is named @effected/plugin, not built yet](config-companion-named-effected-plugin.md) - A future silk-pattern companion package will ship config JSON files and peer-depend on the mcp/cli tools so a consumer's Claude Code plugin and tooling stay on the same versions; the name @effected/plugin is decided, @effected/config is rejected as confusable with @effected/config-file, and the package itself is unbuilt.
* [The config-driven GitHub auth layer reads Config, never process.env](runtimes-config-not-process-env.md) - Token resolution uses Config with a documented precedence between two conventional environment variables, warns on ambiguity, and holds the token Redacted.
* [The effect catalog pins exact versions](effect-catalog-exact-pins.md) - The Effect catalogs pin exact prerelease versions with no caret, never a range.
* [The effected catalog holds next-release versions, and the publish order follows](catalog-holds-next-release-versions.md) - The effected catalog literal resolves each package's next published version rather than its current registry version, which imposes the publish order changesets → catalog:sync → publish and is enforced by a workflow that triggers on pull requests to changeset-release/main.
* [The fidelity obligation and how it is tested](format-fidelity-obligation.md) - A kit formatter changes only key order, whitespace and the trailing newline, and Direction B round-trip testing is what proves it.
* [The jsonl Journal service is a per-registry factory, not a generic key](jsonl-service-is-a-factory.md) - `Journal.Service<Self>()(id, { events })` produces one class per event registry, matching the pattern @effected/config-file already established.
* [The npm tier guardrail — a non-core runtime dependency in a service escalates the whole package](npm-tier-guardrail.md) - @effected/npm stays boundary only while its pure vocabulary never reaches IO and index.ts exports individually; a reachability test asserts both from the source graph, and the answer to the named escalation trigger is a package split, never an accepted retier.
* [The numeric-enum codec is data, not a typescript dependency](numeric-enum-codec-is-data.md) - TypeScript's enum numeric values live in tsconfig-json as a hand-transcribed data table rather than being imported from the typescript package.
* [The release index is Ref-backed with a single atomic load](runtimes-concurrency-safe-index.md) - An index inconsistency between the release set and its lookup map is treated as a programmer error and stays a defect, never a typed failure.
* [The sync form is named `*Result`, never `*Sync`](sync-form-named-result.md) - The kit spells a pure boundary's synchronous twin `*Result`, reserving `*Sync` for genuinely IO-performing sync facades.
* [The typechecker: tsc, not tsgo](tsc-not-tsgo.md) - Every package's types:check runs tsc --noEmit against catalog:build; @effect/tsgo is never added to a package even though the catalog entry still exists.
* [The validation gate ships a real ajv engine, closed by default](schemastore-ajv-ships-closed.md) - SchemaValidator ships a real ajv-backed layer rather than a contract-only seam or a companion package, because a copied adapter is not a shipped default.
* [The yaml lint system stays inside the pure tier](yaml-lint-pure-half-only.md) - The lint engine and built-in rules ship in pure-tier @effected/yaml; file discovery, config-file loading, a CLI and autofix-to-disk are explicitly out of scope for the package.
* [There is no Effect v3 catalog and no camelCase catalog alias](effect3-catalogs-retired.md) - The effect3/effect3:peers catalogs and the effectPeers/effect3Peers camelCase aliases are retired and must not be reintroduced.
* [Vendored Effect is pinned to the catalog tag, not main](vendored-effect-pinned-to-catalog-tag.md) - .repos/effect tracks the release tag matching the effect catalog pin instead of the upstream default branch.
* [WorkspacesSync is a `*Sync` escape hatch, not a `*Result` pure form](workspaces-sync-facade-escape-hatch.md) - The synchronous WorkspacesSync facade exists for a caller that cannot await, and it is named `*Sync` rather than `*Result` because it is a total port over consumer-supplied IO, not a pure computation with a sync twin.
* [app is a composition layer, not an umbrella package](app-is-composition-not-umbrella.md) - app defines no service, schema or error of its own and re-exports nothing from xdg, store or config-file -- a consumer wanting one of them alone takes that package alone.
* [cli files the Command handler-accessor gap upstream rather than shimming it](cli-handler-accessor-gap-filed-upstream.md) - Why a missing accessor on effect/unstable/cli's Command type is reported to core instead of patched locally.
* [cli sets the exit code through core's own Runtime markers](cli-exit-code-via-runtime-markers.md) - Why CliRuntime.reportFailures reads and writes Runtime.errorExitCode / Runtime.errorReported instead of touching process.exitCode.
* [commands' workspaces edge inverts rather than dragging four packages integrated](commands-workspaces-edge-inverts.md) - Why @effected/commands declares LocalExec instead of depending on @effected/workspaces directly.
* [config-file's codecs are free-standing named exports, never a namespace object](codecs-are-free-standing-named-exports.md) - JsonCodec, JsoncCodec, YamlCodec and TomlCodec are four independent module-level exports rather than members of one collecting object.
* [github's github-references compat re-export is droppable, not breaking](github-compat-re-export-droppable.md) - Why the six-name re-export in @effected/github exists, and why removing it later is not a breaking change for the consumer that already adopted the new home.
* [github-actions errors are per-reason tagged unions, not one class with a reason field](github-actions-per-reason-tagged-errors.md) - ActionOutputError, BlobEnvelopeError, CacheKeyError and DetachedProcessError split into a union of classes rather than carrying a shared reason literal.
* [github-references was extracted from github for install weight](github-references-extracted-for-install-weight.md) - Why a pure vendor rule moved out of the client package it was born in.
* [glob is a full-fidelity vendored port, not a minimal runtime dependency](glob-full-fidelity-port.md) - @effected/glob vendors the complete minimatch/brace-expansion/balanced-match dialect with attribution rather than taking minimatch as a runtime dependency or shipping a narrowed subset of its dialect.
* [jsonc's engine/facade split is a cycle firewall](jsonc-engine-facade-split.md) - The vendored scanner/parser in internal/ returns raw records and never imports the facade, which is what keeps noImportCycles satisfiable.
* [memfs takes zero @effected/* edges, ever](memfs-zero-effected-edges.md) - memfs never depends on another @effected package — runtime, peer or dev — because it is the filesystem double every other kit package's tests devDepend on.
* [package-json delegates SPDX license validity to @effected/spdx](spdx-delegation.md) - License.ts validates the license field's SPDX expression grammar by calling @effected/spdx's isValidExpression rather than owning that grammar itself, keeping only the two npm-specific special cases (UNLICENSED, SEE LICENSE IN); the delegation dropped the kit's last foreign spdx-expression-parse runtime dependency.
* [package-json reads the same document through five tolerance tiers](package-json-tolerance-ladder.md) - Package, PackageManifest, LenientManifest, npm's Manifest and the decode-free PackageJsonFormat text path form one strictest-to-most-permissive ladder over the same manifest document, so a caller picks the tolerance its use case actually needs rather than fighting one all-or-nothing decode.
* [pnpm-plugin-effect is deliberately absent from its own effected catalog](plugin-never-in-its-own-catalog.md) - Cataloguing @effected/pnpm-plugin-effect inside the effected catalog it ships would create a release loop with no termination condition.
* [primaryLicense returns none for an AND expression rather than guessing a term](spdx-primary-license-declines-conjunction.md) - A conjunctive SPDX expression has no single license it can honestly be said to be under, so the accessor declines instead of picking the leftmost or any other conjunct.
* [runtimes reads GitHub over core HttpClient, never Octokit](runtimes-http-over-core-no-octokit.md) - @effected/runtimes' two authenticated REST reads go through effect/unstable/http directly, with GitHub App auth left as a pluggable seam rather than a built-in.
* [runtimes' error ladder keeps four distinctions the pipeline must not collapse](runtimes-error-ladder.md) - Structured Schema.TaggedError classes with no free-text message field, and four cases (invalid range, unresolvable default, auth method, no-match tag) that must stay separately typed.
* [sbom owns its own CycloneDX emitter, declining the object-model library](sbom-owns-its-emitter.md) - @effected/sbom hand-rolls a CycloneDX 1.6 model and serializer rather than depending on @cyclonedx/cyclonedx-library.
* [semver's parse and intersect Results are the primitive](semver-result-is-the-primitive.md) - SemVer.parseResult, Range.parseResult, Comparator.parseResult and Range.intersectResult hold the engine; their Effect twins derive from them and never re-implement it.
* [templates owns the mechanism, never the content](templates-mechanism-not-content.md) - Why @effected/templates carries no vendor naming, section vocabulary, or file-ordering policy of its own.
* [toml is a full-parity package built from scratch](toml-full-parity-from-scratch.md) - @effected/toml ships parse, stringify, Schema, a lossless CST, edit-in-place, formatter and visitor on a from-scratch engine, rather than a minimal port with only what the first consumer needs.
* [tsconfig-json is one package, not a pure-schema/boundary-IO split](tsconfig-one-package-not-two.md) - tsconfig-json keeps schemas and file IO in one boundary-tier package rather than splitting into a pure schema package plus a separate IO package.
* [xdg does not depend on store](xdg-does-not-depend-on-store.md) - XDG resolution stays boundary tier by never taking a workspace edge on the integrated-tier store package -- the SQLite database services were split out precisely to keep this split possible.
