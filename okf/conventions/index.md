# Convention

* [A generator's data input is a committed file, not a submodule](generator-input-is-a-committed-file.md) - Vendor a source repository as a git submodule only when a package needs to read the repository; commit the one document a generator actually reads.
* [A package that commits fixtures commits a provenance README beside them](fixtures-carry-provenance-readme.md) - Every committed fixture directory carries a README stating the producing tool and version, the exact generating command, whether the fixture is hand-authored and why, and the property it exists to pin.
* [A plugin skill is a lean index over references](skill-shape.md) - Every SKILL.md is an intro, a construct-to-import table, positive-imperative standards, one-line footguns pointing at a reference, and a described Load-when-guarded resources list — depth lives one level down in references/, never nested.
* [A public name must not collide with an effect root export](no-effect-root-name-collision.md) - Check every candidate public name against effect's root exports before committing to it, because every consumer in this ecosystem already imports from effect.
* [Agents never run pnpm:up, pnpm:preview, or pnpm:export](agents-never-run-pnpm-up.md) - The three commands that advance and export the Effect catalogs mutate the lockfile and root pnpm-workspace.yaml and are reserved for the user to run; agents surface the command instead. catalog:check and catalog:sync are a different, agent-safe class.
* [Build a GitHub Action repository to the kit's canonical shape](github-action-canon.md) - A GitHub Action built on @effected follows one file layout, one design sequence, and eleven resolved rules derived from the three actions that completed the migration onto @effected/github-actions — deviate only for a documented, revisable reason.
* [Build through turbo, never by invoking the bundler script directly](build-through-turbo-only.md) - Always build with \`pnpm build --filter \<pkg\>\`, which drives turbo's full task graph, and never invoke a package's savvy.build.ts directly or list @savvy-web/bundler as a runtime dependency.
* [Change the Claude Code plugin first, then port to Copilot](plugin-claude-code-first.md) - Author every skill, agent and hook change in plugins/claude-code/ and prove it there before copying and refactoring it into plugins/copilot/'s format, never the reverse.
* [Climb the evidence ladder in order — renames, then source, then a probe](evidence-ladder.md) - Settle a claim about Effect v4 at the cheapest rung that actually answers the question -- migration notes and skill guides for renames, vendored or installed source for existence and signature, and only a probe from inside a package for semantics.
* [Dependency policy: R1-R4](dependency-policy.md) - The four rules governing how a library's tier and its dependencies relate, including when a retier to integrated is admissible.
* [Error handling standards](error-standards.md) - The error-type preference order, where errors are defined, the Failure/Defect/Interrupt distinction, and the rule that every declared error channel must be demonstrated fireable.
* [Every commit follows the conventional-commit and DCO contract](commit-message-contract.md) - Commits require a conventional type, a DCO signoff, and bodies restricted to dash bullets with no headers, numbered lists, code fences, links, or more than two inline-code spans.
* [Every git constructor and error path carries the redaction mask](git-redaction-policy.md) - A GitCommand constructor masks its own sensitive positionals into GitInvocation.redactedArgs; classify and span annotations must use only the redacted form.
* [Every package carries the same manifest shape and file set](package-manifest-and-scaffold.md) - A pure-tier package mirrors a sibling's file manifest and package.json shape byte-for-byte except for the fields that are load-bearing per-package.
* [Format-package convention](format-package-convention.md) - How @effected/\* packages expose formatting as distinct from validation, and the fidelity guarantee a kit formatter makes.
* [Input-hardening standards](input-hardening-standards.md) - Untrusted input and recursive walks fail through the typed error channel, never as a stack-overflow defect; nesting depth and reference-expansion are both capped and bounded.
* [Keep the tree resolved to one effect copy](one-resolved-effect-copy.md) - The whole workspace and its build toolchain must resolve to exactly one installed copy of effect, on the prerelease the catalogs pin.
* [Module layout is module-per-concept, not kind-based folders](module-per-concept-layout.md) - Structure every package's src/ as one file per public concept rather than as errors/, schemas/, services/, layers/ folders.
* [Never hand-edit the construct index — regenerate it](construct-index-is-generated.md) - The construct-index tables under skills/effected-packages/references/constructs/ are generated output; edit construct-annotations.json and rerun the generator instead of touching a table directly.
* [Never undo unexpected working-tree changes with git checkout, restore, or stash](never-undo-with-git-checkout.md) - Inspect and repair unexpected working-tree changes by hand instead of discarding them, because other agents and earlier automated steps may hold uncommitted work in the same tree.
* [Never write under .repos/](no-writes-under-repos.md) - .repos/ holds read-only vendored reference source; use the repos management tooling instead of Write, Edit, Bash, or any MCP git operation against it, and never expect it in a build or lint graph.
* [No @effected/\* package imports typescript](no-typescript-imports.md) - @effected/\* packages never import the typescript package, at runtime or as import type; version-coupled TypeScript knowledge is owned by tsconfig-json as data tables, and direct TS-API usage stays confined to external consumers until a TypeScript 7.1 JS-compatible API exists.
* [Observability standards](observability-standards.md) - Named spans by default, structured logging at operation boundaries, and the division of responsibility between libraries (instrument) and applications (configure telemetry backends).
* [Only entrypoint files re-export; never a barrel or a namespace object](no-barrel-re-exports.md) - Restrict re-exports to src/index.ts and published subpath entrypoints; every other module imports explicitly, and grouped implementations that each reach a distinct engine are never collected into one binding.
* [Peer-dependency discipline](peer-dependency-discipline.md) - Every package declares its complete peer closure; libraries keep effect as a peer; internal @effected edges float on workspace:^ so consumer trees dedupe onto one copy.
* [Pin heavy-dependency confinement with a reachability suite that has a positive control](bundle-reachability-suite.md) - A structural test walks a package's runtime import graph to prove which modules may reach a heavy dependency, and must also prove it can fail.
* [Plan a surface's first consumer port as a design round](first-port-is-a-design-round.md) - A first consumer of a kit surface reports absence, not mere mis-projection — plan its port as a design round that may reshape the surface, never as an absorption round that merely wires an existing API to a new caller.
* [Read publishability from publishConfig.access, never from private](publishability-signal.md) - Every source package.json in this repo is "private" true by design; the machine-checkable signal for whether a package publishes is publishConfig.access === "public", set by the bundler's manifest transform, not the source private field.
* [Require the consolidated core's contract in R; never re-implement or re-declare it](require-in-r-default.md) - Effect v4 folded platform, rpc and cluster contracts into core; a library needing one requires the core service in R and lets the app provide the platform layer, and never builds its own backend for a contract core already declares.
* [Schema standards](schema-standards.md) - How @effected libraries model domain data with Effect Schema — Class over Struct, make vs parse, brand and Opaque, and the wire-provenance rule for byte-fidelity replay.
* [Services and layers standards](service-and-layer-standards.md) - Services as Context.Service classes, layers exported beside them, composition rules, and the swappable-contract discipline that keeps a default from becoming ambient policy.
* [State which count moved and why, whenever a gate's number changes](state-the-reason-when-a-gate-count-moves.md) - Three of this repository's gates are assertions that a number did not change unexpectedly; when one moves, name the count and the reason in the report, or an unexplained change is indistinguishable from a regression.
* [Support the current major and one back of every package manager](package-manager-support-policy.md) - The kit provisions and models the current major and one major back of every package manager — pnpm 11 + 12 and npm 11 + 12, both pairs verified as of 2026-09-18 — detecting an artifact layout by what the manifest declares, never by major; older majors get no code paths, tests, fixtures or docs.
* [Sync-primitive policy](sync-primitive-policy.md) - A pure kit boundary exposes the sync form as its primitive; the Effect form is derived from it and adds only the tracing span.
* [Testing standards](testing-standards.md) - @effect/vitest as the default runner, assert.\* never expect, memfs as the real filesystem double, and why the oracle for a ported algorithm must be external.
* [Treat line endings as a first-class invariant in any file-rewriting code](line-endings-first-class.md) - Detect and preserve a document's dominant EOL, and normalize for comparison rather than for storage, or drift detection silently breaks on CRLF input.
* [Write changesets once, at branch finalization, never per round](hold-changesets-until-branch-end.md) - Reconcile a branch's changesets in a single pass when the work concludes, instead of adding or editing one after every incremental round of changes.
