# Measurement

* [CI's Run Tests step took 21 minutes, half of the file time in five files](ci-test-duration.md) - On the Effect 4.1.5 pull request's CI run the Run Tests step took 21 minutes (6 build, 15 vitest over 1006 files); the top five files took about 835 of 1673 seconds of file time, and coverage made the sweeps 2.5 to 3 times slower locally. After the tiers, PR 1444's critical path took 8 minutes warm and 12.9 cold.
* [Sampling markdown-lint's corpus cut its local file time from 1,675 s to 160 s, short of the 240 s CI gate's proportion](corpus-sample-test-time.md) - On PR 1414 the Run Tests step took 38 minutes, 3,640 of 4,186 s of file time in markdown-lint. An 11-fixture corpus sample ran in 160 s against 1,675 s locally (9.6%, where the 240 s CI gate needs 6.6%) with source coverage within a point of the full corpus; on PR 1419 the Run Tests step then took 9 min 53 s (3 min 5 s build, 401 s vitest) with markdown-lint at 252 s.
