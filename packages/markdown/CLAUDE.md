# CLAUDE.md — @effected/markdown

CommonMark 0.31.2 + GFM as pure Effect schemas: parse into mdast-shaped nodes
with byte offsets, compute offset-splice edits, format, modify by node, project
to and from plain mdast, walk as a `Stream`, and read and write frontmatter
through free-standing codecs. **Tier: pure** — no IO, one runtime dep (the dependency-free `@effected/source`,
whose `LineIndex` positions every node and diagnostic),
optional kit peers only for the frontmatter codecs.

Durable knowledge about this package lives in the OKF bundle, not here. Load
the concept a task needs:

- `okf/modules/markdown.md` — Load when: touching anything in `src/` — the
  engine (two-phase commonmark.js port, dialect registries, the raw-carrier
  cycle firewall), the node shape and its deliberate deltas from
  commonmark.js/mdast, hardening (`MAX_NESTING_DEPTH`, the paren cap, the
  pathological suite), navigation and section finders, the edit/format/modify
  layer, testing corpora and the differential oracle, or the build.
- `okf/conventions/markdown-canonical-form-is-a-published-commitment.md` —
  Load when: changing anything `Markdown.stringify` emits; a canonical row that
  moves is a breaking change and three copies of the table move together.
  `Text.escapeStyle: "literal"` is the one escaping opt-out (block-structure
  escapes kept) and the one fidelity field `Mdast.fromMdast` admits.
- `okf/decisions/markdown-dialects-closed-set.md`,
  `okf/decisions/markdown-editing-is-offset-splice.md` — Load when: tempted to
  add a public extension API or a lossless CST; both were decided against.
- `okf/interfaces/markdown-frontmatter.md`,
  `okf/gotchas/markdown-frontmatter-write-loses-untracked-data.md`,
  `okf/limitations/markdown-modify-refuses-frontmatter.md` — Load when: working
  on a frontmatter codec, the capture toggle and `hasFrontmatterBlock`, the
  `$schema` resolver grammar, `FrontmatterSource.split`/`join`, or the optional
  `yaml`/`toml`/`jsonc` peers.
- `okf/interfaces/markdown-mdx.md`,
  `okf/decisions/markdown-mdx-escape-presence-keyed.md` — Load when: touching
  an MDX node class, the unions it widens, or how the stringifier serializes it.
- `okf/gotchas/languageless-code-node-indents.md` — Load when: a synthesized
  `Code` node serializes indented and someone calls that a bug.
- `okf/gotchas/markdown-red-tripwire-may-mean-a-limitation-moved.md` — Load

## Scope

Markdown→HTML and HTML→markdown are permanently out of scope as product
features; `__test__/e2e/support/htmlWriter.ts` is test-harness machinery — do
not promote it to `src/`. Never add a public extension API: a dialect is a
registry composition and a future one lands as construct modules only.

## Working here

```bash
pnpm vitest run packages/markdown/__test__   # this package's tests
pnpm build --filter @effected/markdown       # dev + prod, in order
```

- Tests use `@effect/vitest` and `assert.*` — **never `expect`** — and live in
  `__test__/` (conformance in `__test__/e2e/`), never in `src/`. Assert
  `position` with `deepStrictEqual`, never `strictEqual`: `make` re-constructs
  nested values.
- `src/internal/` throws raw carriers and **never imports a public module**;
  that house rule is what holds error-level `noImportCycles`.
- `src/internal/entityMap.ts` is generated by
  `__test__/tools/generate-entities.ts` from the WHATWG entity document —
  hand-run, never in CI; never edit it by hand, and accept a regeneration only
  on entry-for-entry data equality with the old map.
- The `commonmark` oracle is an exact-pinned devDependency imported only by
  `__test__/oracle.property.test.ts` — never a runtime dep, never elsewhere.
- Never run `node savvy.build.ts --target prod`: it skips `build:dev`, emits no
  `.d.ts`, and leaves a truncated `issues.json` shaped like a clean gate.
- `savvy.build.ts` carries one narrow API Extractor suppression
  (`ae-forgotten-export` / `_base`) for inline class-factory heritage symbols.
  **Never widen it.** `package.json` stays `"private": true` — the bundler
  emits the publishable manifest.
